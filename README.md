# Univers CRM

CRM web multi-tenant pentru gestionarea clienților, lead-urilor și vânzărilor.
Stack: Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · shadcn/ui · Supabase.

```bash
npm install
npm run dev        # http://localhost:3000
npm run test       # teste unitare (Vitest)
npm run test:e2e   # teste E2E (Playwright)
```
